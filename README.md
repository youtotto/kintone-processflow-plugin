# ProcessFlow for kintone

ProcessFlow for kintoneは、工程別フォーム・業務説明・プロセス案内を無料で利用できるプラグインです。標準の操作欄から条件一覧を開き、項目の「プロセス条件」でも概要を確認できます。

Releaseから `processflow-for-kintone-2.0.0-free-bundle.zip` を取得して展開し、中の `processflow-for-kintone-2.0.0-free-plugin.zip` をkintoneへ読み込んでください。PC版kintone向けです。詳しくは同梱の利用ガイドをご確認ください。

プロセスの追加条件5種類とアプリ連携はProcessFlow Proの機能です。製品紹介：https://www.nestrec.com/post/process-form-for-kintone

無料版とPro版は同じプラグインIDを使います。無料版へ入れ替えるとPro追加条件は適用されなくなるため、管理者は運用条件を確認してから入れ替えてください。
